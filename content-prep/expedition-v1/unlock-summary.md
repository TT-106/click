## 核心解锁链(主干资格链,设计7.2)

```
免费手作(初始) → 工坊一级 ∕ 水井一级 → 炉窑一级 → 工坊二级 → 地图室二级 ∕ 前哨
```

- 工坊一级(L1):木料12kg + 石料6kg + 纤维1kg,**全部原料**,从零可启动。
- 炉窑一级(L1):石料20kg + 黏土8kg + 木料8kg,**全部原料**;铁冶炼不要求铁锭,无循环资格。
- 工坊二级:木板8 + 绳索2 + 铁锭2 → 由工坊一级/手作与炉窑一级供给；R54已用配方/建筑联合启动可达性检查，不再仅以SCC判断。
- 园圃、补给所和库房效率升级可并行;没有必须八栋全满才能出发的条件。

## 效率量纲约定

- `craftSpeedMultiplier` / `productionSpeedMultiplier` / `restSpeedMultiplier`:**基础时间 ÷ 倍率**;1.1 = +10% 速度(时间×0.909),不是"时间-10%"。
- `loadUnloadTimeMultiplier`(仓库装卸):**时间倍率**,0.9 = 装卸时间 -10%;三级总 -20% = 0.8。
- `dryGoodsSoftTargetG`(仓库软目标):250/500/1000 kg;**水量目标仅由水井 20/40/60 kg 决定**,仓库不限制水量。
- 水井目标储量为20/40/60kg；配方时间分别120000/108000/96000ms，相对一级速度为1、120000/108000（约1.111）、1.25。productionSpeedRatioFromL1仅作说明，不再次加速配方。
