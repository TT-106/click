## 已按原设计记录的替代与边界

- 铜锭/铁锭 → nails:`anyOf`,不同时扣。
- 煤/木炭 → 精钢:`anyOf`,仅选一种。
- 兽骨8根/甲壳8片 → 骨甲护甲:`anyOf`,内部 variant 区分材质,不复制物品定义。
- 药草/凝胶 → 治疗药剂;晶石/魔力尘 → 专注药剂:`anyOf` 替代配方。
- 手作变体:木板/绳索 handcraft 4分钟、口粮篝火 2分钟(免费工位,速度为工坊/补给所一半)。
- 水井 L1/L2/L3 = 120000/108000/96000 ms 每批 1kg(设计"约+11%/总+25%"换算);蓄水目标 20/40/60 kg 属建筑字段不属配方。
- 实例升级 5 条(staff-crystal / bow-hardwood / short-sword-steel / leather-coat-weathered / focus-silver):`operation: upgrade-instance`,输出=原实例(禁止复制),记录升级后质量与材质;旧件不再入仓。
- `visibleWhen` 隐藏规则:combat-consumers(治疗/解毒/绷带/武器护具)、casting-consumers(专注药剂/法器)、night-content(火把/提灯)、environment-states(保暖/清凉)。无消费者的配方在未启用前必须隐藏。
