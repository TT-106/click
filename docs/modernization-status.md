# 现代化验收口径

本文件只定义“完成”怎样判断；当前指标与最近验证统一见 [WORKSTATE](WORKSTATE.md)。逐轮改名与解耦经过已移至 [历史进展](history/modernization-through-R50.md)。

| 目标 | 当前实现与证据边界 | 完成判断 |
|---|---|---|
| 产品运行与原版反编译脚本分离 | src 静态 ESM 运行，build 审计源码及 dist；原版只作 oracle | 产品入口/构建不导入 archive/original，不要求删除原版参照 |
| 保持经典行为与存档兼容 | 同 fixture 的 parity、场景差分、DOM 与像素检查存在；矩阵仍有四条 PARTIAL | 分系统保留覆盖和缺口；全绿不是所有真实版本/设备都等价 |
| 现代命名与架构 | 大量恢复期属性和局部名已语义化，视图/统计等逐步注入；大 SCC、共享 game 与类型债仍存在 | 接口降低修改传播与理解成本，可独立测试；命名或 SCC 数字不是单独完成条件 |
| 原野/桌面产品 | 已有短采集闭环和窗口/保存能力；新经济、原创角色/战斗、长期时间设计缺失 | 按产品待办验收真实可用功能，不用经典恢复矩阵冒充原野全功能验收 |

classic 和 clean 分开验收，已授权的 clean 表现不要求逐像素等于原版。经典正常数值、RNG 和存档键继续保留；名称输出/故障停机按已实现的可靠性修正验收。

结论：恢复工程已形成可验证基础，完整现代化与独立原创游戏均未完成。待办的唯一工程入口是 [REMAINING-WORK](REMAINING-WORK.md)，产品范围在 [GAME-PRODUCT-TODO](GAME-PRODUCT-TODO.md)。
