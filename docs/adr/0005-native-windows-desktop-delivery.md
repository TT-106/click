# 以无 WebView 的 Windows 桌面游戏交付

本体以不使用 WebView 的 Windows 桌面游戏交付。首个可验收产物应包含全部所需素材，离线双击即可运行；窗口可调整大小并支持全屏，在 1280×720 与 1920×1080 检查地图、战斗、面板和像素清晰度。游戏自身的功能与快捷键需要保留，第三方浏览器用户脚本及其 DOM 接口不作为桌面产品的兼容目标。选择原生游戏呈现意味着现有 DOM/CSS 浏览器界面不能直接作为正式界面沿用，需重新实现并验证交互与视觉表现。游戏引擎与规则核心的边界见 0007 号决策。

流畅度以当前 Windows 电脑上的 1920×1080 未暂停实战连续 10 分钟为验收场景：目标 60 FPS，95% 帧耗时不超过 16.7 毫秒，95% 操作到可见反馈耗时不超过 100 毫秒。记录实际使用的显卡、帧时间分布和场景，避免将本机结果推广为其他硬件保证。
