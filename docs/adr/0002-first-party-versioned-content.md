# 新增内容先采用项目内版本化内容包

未来新增地图、人物、技能和玩法时，先采用项目内维护的版本化内容包，并为注册、校验和新引擎存档的版本演进划定边界。玩家可以为已有存档选择新内容，选择先记为待启用；队伍离开当前地牢或城堡、回到世界地图，且战斗、掉落和行动均结算完成后，先备份再启用。已生成的世界、当前实例和已消耗的随机序列不得被追溯改写；新增地牢主题只用于以后生成的地牢，职业与技能分别在原有选择与学习入口出现。未启用内容不得改变本体的随机流；启用后的新规则可以影响未来进程，并须记录内容版本与随机流来源。每个存档记录实际启用的包及版本，也保留待启用选择，避免重启后丢失意图。若已启用的内容包缺失或版本不兼容，保留原档并暂停载入，显示缺少的包与版本；只有补齐内容或经过验证的迁移后继续。仅待启用内容包缺失时保留选择并提示，暂停该包的激活，本体进度仍可继续。当前没有需要支持的第三方模组案例；在真实需求明确前，不将公开模组接口和热加载作为本轮架构目标。
